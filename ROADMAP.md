# Roadmap

## Implemented

- Bounded Server-Sent Events framing with the package-native HTTP streaming contract.
- Safe default response headers and pull/write backpressure without an internal event queue.

## Release gates

- Hosted CI across supported language versions and dependency/security review.
- HTTP server and ingress flush, cancellation, and disconnect interoperability.
- Representative concurrent-stream load and soak measurements.
- Artifact integrity and release provenance.
