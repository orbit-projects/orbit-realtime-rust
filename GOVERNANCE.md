# Governance

This repository is an independently installable, community-developed Orbit language implementation. Governance describes project practice; it does not grant hosting-platform access or change branch protection.

Routine technical changes proceed through reviewed pull requests. Record an ADR under `docs/architecture/adr/` when changing a public contract, dependency boundary, lifecycle owner, security policy, supported runtime, or compatibility policy. Only authorized maintainers publish releases or change repository settings. Stable releases require local and hosted validation, dependency review, artifact integrity, and provenance evidence; a green local build alone is not release evidence.
