# Contributing to Orbit Realtime Rust

Contributions are welcome. Read the README and architecture, operations, and security guides before changing public behavior. Keep changes within this implementation's contract and preserve the Orbit capability boundary.

Use the commands in the development guide. Add regression coverage for behavior changes, update user-facing docs and `CHANGELOG.md` for public changes, and state the validation performed. Keep credentials, personal data, local environments, caches, and build artifacts out of source control. Do not commit, publish, or change repository settings as part of local implementation work. Contributions are licensed under Apache-2.0.
